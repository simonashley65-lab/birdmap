Birdmap setup

Add the app to your home screen, then set up the two Safari bookmarks that refresh the BirdGuides layer and your year list from your phone.

1. Add to home screen

Open the app in Safari, tap the Share button, then Add to Home Screen. It opens full-screen from then on, and eBird data loads live every time you open it.

2. BirdGuides bookmarklet

eBird is live, but BirdGuides needs your logged-in session, so the app imports it from a BirdGuides page you have open. Set this up once:

aOn the iPhone: copy the code in the box below, bookmark any page, then edit that bookmark and paste the code in as its address. Name it bgx. (On a Mac you can drag the button below straight onto the Favourites bar instead. Tapping the button here runs it on this page, which does nothing useful.)

Import BirdGuides → Birdmap

bIn Safari, open BirdGuides sightings, filter to the county and the last 7 days, set results to 1000, and Search.
cRun the bookmark on that page. In Safari: open Bookmarks and tap bgx. In Chrome: tap the address bar, type bgx, and tap the bookmark in the suggestions. You'll land back in Birdmap with the new reports merged in; sightings at sites the app has no coordinates for are skipped and named in the message.

3. Year list / life list bookmarklet

One bookmark does both. Open your eBird year list and run it to update "Still to see in 2026"; open your UK life list and run it to update the ★ lifer markers. It works out which page it's on.

Update year list → Birdmap

Save it as a bookmark named ylx the same way, and run it on either list page (Safari: Bookmarks → ylx; Chrome: type ylx in the address bar).

Notes

Imports are stored on the phone only. The region, filters and skipped sites are remembered per device. If something looks stale, tap Refresh in the header; eBird data refreshes automatically after 15 minutes in the background.
