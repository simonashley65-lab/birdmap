# Birdmap

Live coastal bird sightings for a chosen stretch of coast — eBird fetched live from the phone, BirdGuides imported via a Safari bookmarklet, species ranked against a personal year list.

Open `index.html` (GitHub Pages) and add it to the home screen. `help.html` has the bookmarklet setup.

## Files
- `index.html`, `app.js`, `app.css` — the app (vanilla JS + Leaflet, no build step)
- `data/regions.json` — per-region config (eBird region codes, bbox, area groupings, coastline polygon, BirdGuides site coordinates) plus the latest BirdGuides snapshot and rarity grades
- `data/taxonomy.json` — eBird GB taxonomy (en_UK names, taxonomic order, family)
- `data/yearlist.json` — eBird species codes on the year list
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA shell

Data files are regenerated by `build_data.py` (kept in the Claude project) from BirdGuides/eBird pulls.
